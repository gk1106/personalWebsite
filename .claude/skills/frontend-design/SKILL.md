# Frontend Design Skill

Create a distinctive premium engineering portfolio.

Priorities:
1. Strong hierarchy
2. Grid-based composition
3. Dark editorial aesthetic
4. Gold + sky-blue accents
5. Glass surfaces used selectively
6. Excellent whitespace
7. Responsive behavior

Use the supplied visual reference as inspiration for the grid, density, typography rhythm and card language. Never copy its text, images, branding, or exact layout.

Every section must have a clear visual purpose.
